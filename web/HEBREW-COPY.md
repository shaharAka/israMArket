# Hebrew copy guide for IsraMarket

The reader is an Israeli small-business owner reading on a phone between customers. The
copy should sound like a sharp Israeli friend who knows marketing — not like a translated
SaaS product. Read every string out loud: if an Israeli wouldn't say it that way, rewrite it.

This complements `UI-RULES.md` (word budgets, one primary action, honesty). Nothing here
overrides the honesty rule: caveats, "we can't measure this" and sources stay.

## 1. Write Hebrew first, never translate

The most common failure is English phrasing in Hebrew words. Rewrite the idea, don't
swap the words.

| Calque (avoid) | Why | Natural Hebrew |
|---|---|---|
| איך העסק שלכם **נשמע** | "how your business sounds" — brands don't "sound" in Hebrew | איך העסק שלכם נראה ומדבר / הסגנון של העסק |
| כתוב **בקול שלכם** | "in your voice" | בסגנון שלכם / כמו שאתם מדברים |
| שיווק **שעובד** | "marketing that works" | שיווק לעסקים קטנים / שיווק בלי כאב ראש |
| **הציגו את** המותג | "show the brand" | לקרוא את האתר / תראו לי |
| **לעשות** הבדל / **בסוף היום** / **לקחת** את זה הלאה | English idioms | say the concrete thing |
| **מבוסס** על / **מונע** על ידי | "based on / driven by" | לפי / בגלל |
| **חוויה** / **פתרון** / **מסע** | SaaS filler | name the actual thing |
| שחרר / **אפשר** לכם (enable) | "unlock / enable" | עכשיו אפשר / תוכלו |

## 2. Address and verbs

- Address the owner in **plural second person** (אתם, תוכלו, שלכם). It is gender-neutral
  and standard in Israeli product copy. Never mix in singular (אתה/את) or "המשתמש".
- **Buttons and links: infinitive** — `לאשר`, `לבדוק ולאשר`, `לקרוא את האתר`,
  `לבנות את החודש`. Not imperative (`אשרו`), not a noun (`אישור`) unless it's a tab label.
- **Instructions in body text: plural imperative** — `הזינו`, `בחרו`, `חברו`.
- **Status and progress: present tense, "we"** — `קוראים את האתר…`, `כותבים את הפוסטים…`.
- Avoid verb forms that force a gender. Rephrase `מוכן/מוכנה` → `הכול מוכן`.

## 3. Short and concrete

- One idea per sentence. Prefer two short sentences over one with a dash.
- Lead with the thing the owner cares about: the post, the customer, the shekel.
- Cut words that restate the control next to them (`לחצו כאן כדי…`).
- Numbers as digits (`3 פוסטים`, `4,500 ₪`), shekel sign after the number.

## 4. Punctuation

- Use the em dash (—) sparingly: at most one per paragraph. Usually a comma, a colon or a
  full stop reads better in Hebrew.
- Hebrew geresh/gershayim: `א׳`, `ש״ח` — not `'` / `"`.
- Ellipsis `…` only on loading states.
- No exclamation marks in UI copy, except in a generated post's caption.

## 5. Words we use (glossary)

Use these consistently. A term changes only if it changes everywhere.

| Concept | Say | Don't say |
|---|---|---|
| a piece of content | פוסט | תוכן, קריאייטיב |
| approve | לאשר, אושר | לאמת, לתקף |
| the monthly/quarterly plan | התוכנית (של החודש / של הרבעון) | אסטרטגיה, רודמאפ |
| the business's photos & videos | התמונות שלי | נכסים, מדיה, ספריית מדיה |
| website analytics | נתוני האתר | GA4, גוגל אנליטיקס (only once, in an explanation) |
| an inquiry / order | פנייה, הזמנה | ליד, המרה, קונברז׳ן |
| visits to the site | כניסות לאתר | סשנים, טראפיק |
| target audience | קהל, למי פונים | סגמנט, פרסונה |
| people who already know you | מי שכבר מכיר אתכם | רימרקטינג |
| cost to get one customer | כמה עולה להביא לקוח | CPA, CAC |
| brand voice | הסגנון, איך אתם מדברים | הטון (ok as a label), הקול |
| connect an account | לחבר | לסנכרן, לאנטגרט |

English brand names in Hebrew letters: גוגל, אינסטגרם, פייסבוק, וואטסאפ.
Acronyms (ROAS, CPC, CTR, SEO, UTM, OAuth, API) never appear in owner-facing copy.
**Exception: "AI"** — Israelis say it, so write `AI` (e.g. `תמונה שנוצרה ב-AI`, `ליצור ב-AI`), not `בינה מלאכותית`.

## 6. Before / after (from the landing page)

| Before | After |
|---|---|
| תנו לנו את האתר. נראה איך העסק שלכם נשמע. | הכניסו את האתר. נחזיר לכם פוסט ראשון. |
| שיווק שעובד בישראל | שיווק לעסקים קטנים |
| הציגו את המותג | לקרוא את האתר |
| פוסט אחד לדוגמה, כתוב בקול שלכם | פוסט לדוגמה, בסגנון שלכם |
| אין כאן אחוזי פניות מומצאים. | לא נמציא לכם מספרים. |
